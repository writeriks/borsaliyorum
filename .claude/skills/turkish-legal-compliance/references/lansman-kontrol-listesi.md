# Lansman Öncesi Hukuki Kontrol Listesi

Her madde için sahip + durum tutulur. ⚖️ = avukat onayı gerekli.

## Metinler
- [ ] ⚖️ Kullanım Koşulları (yasaklı içerik, manipülasyon/içeriden bilgi yasağı, sponsorlu içerik beyanı, içerik lisansı, yaptırımlar, uyuşmazlık/yetkili mahkeme)
- [ ] ⚖️ KVKK Aydınlatma Metni (üyelik, log, analitik, pazarlama ayrı bölümler; alt işleyen listesi)
- [ ] ⚖️ Açık Rıza Metinleri (pazarlama iletisi, analitik/reklam çerezleri, yurt dışı aktarım gerekiyorsa)
- [ ] ⚖️ Çerez Politikası + çerez listesi
- [ ] ⚖️ Yatırım tavsiyesi değildir uyarısı + yerleşim planı
- [ ] ⚖️ Topluluk Kuralları / Moderasyon Politikası
- [ ] ⚖️ (Premium varsa) Ön bilgilendirme formu, mesafeli satış sözleşmesi, iade/cayma politikası
- [ ] Künye / iletişim sayfası (yer sağlayıcı bilgileri, resmi talep iletişim adresi)
- [ ] KVKK başvuru formu ve kanalı

## Süreçler
- [ ] Kişisel veri envanteri ve saklama/imha politikası

- [ ] VERBIS yükümlülük kontrolü (güncel eşik)
- [ ] Veri ihlali müdahale planı (72 saat)
- [ ] İlgili kişi başvuru süreci (30 gün), "verilerimi indir", "hesabımı sil"
- [ ] İçerik kaldırma / resmi talep süreci ve sorumlu kişi
- [ ] 5651 trafik log saklama (append-only, erişim kontrollü)
- [ ] İYS kaydı (pazarlama iletisi gönderilecekse)
- [ ] Piyasa verisi lisansı / widget kullanım şartları
- [ ] Marka tescil kontrolü
